Tablas HTML

¿Qué son las tablas?

Las tablas HTML sirven para organizar información en filas y columnas. Son útiles para mostrar calificaciones, horarios, precios y otros datos que se necesitan comparar de forma ordenada.

Elementos de una tabla

  • table: representa la tabla.
  • tr: crea una fila.
  • th: identifica una celda de encabezado.
  • td: contiene los datos de una celda.
  • caption: proporciona un título a la tabla.

Atributos y características

  • colspan: permite que una celda ocupe varias columnas.
  • rowspan: permite que una celda ocupe varias filas.
  • scope: identifica las celdas relacionadas con un encabezado.

Importancia de las tablas

Las tablas facilitan la comparación de datos y permiten presentar información de forma clara. Es recomendable utilizarlas para datos relacionados y no solamente para acomodar el diseño de una página.
