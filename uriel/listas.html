Listas HTML

¿Qué son las listas?

Las listas HTML permiten agrupar información relacionada. Se utilizan para mostrar características, instrucciones, materiales y otros elementos que necesitan una organización clara.

Lista desordenada

La lista desordenada presenta elementos sin un orden numérico obligatorio.

  • Computadora
  • Teclado
  • Ratón
  • Monitor

Lista ordenada

La lista ordenada presenta elementos siguiendo una secuencia.

  1. Encender la computadora.
  2. Abrir el navegador.
  3. Ingresar a una página web.
  4. Consultar la información.

Ventajas de las listas

  • Organizan los datos.
  • Facilitan la lectura.
  • Separan las ideas principales.
  • Ayudan a comprender instrucciones.
