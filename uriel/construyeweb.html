CONSTRUYE APLICACONES WEB


Introducción

En este proyecto conoceremos los principales elementos que se utilizan para crear páginas web mediante HTML y CSS. Estos lenguajes son importantes en el desarrollo web, ya que permiten organizar la información y mejorar la apariencia de los sitios de Internet.

HTML es un lenguaje de marcado que permite agregar títulos, párrafos, imágenes, listas, tablas, formularios e hipervínculos. También cuenta con etiquetas semánticas que ayudan a organizar el contenido de una página web de manera clara y ordenada.

Por otra parte, CSS es un lenguaje que se utiliza para dar estilo a las páginas web. Con él podemos cambiar los colores, los tipos de letra, los tamaños, los fondos, los márgenes y la distribución de los elementos. También permite crear diseños que se adapten a diferentes tamaños de pantalla.

Durante este proyecto se presentarán ejemplos de estructuras semánticas, formularios, tablas, listas, etiquetas HTML, hipervínculos y estilos CSS. Cada tema tendrá su propio código para facilitar su comprensión, organización y práctica.

El objetivo principal es aprender a utilizar estos elementos de manera correcta, comprender para qué sirve cada uno y desarrollar páginas web sencillas, ordenadas y fáciles de utilizar.


Objetivo del proyecto

Comprender los fundamentos de HTML y CSS mediante ejemplos prácticos que permitan crear páginas web, organizar información, enlazar documentos y aplicar diferentes estilos visuales.


Temas que se desarrollarán

  • Estructura semántica de HTML.
  • Formularios y sus atributos.
  • Tablas y organización de datos.
  • Listas ordenadas y desordenadas.
  • Hipervínculos y enlaces internos.
  • Etiquetas y atributos HTML.
  • Estilos de hipervínculos con CSS.
  • Selectores y propiedades CSS.
  • Diseño y presentación de páginas web.
