Selectores y propiedades CSS

¿Qué es CSS?

CSS es un lenguaje que permite cambiar la apariencia de las páginas web. Se utiliza para modificar colores, tamaños de letra, espacios, bordes y la distribución de los elementos.

Tipos de selectores

  • Selector de etiqueta: aplica estilos a elementos como p o h1.
  • Selector de clase: utiliza un nombre precedido por un punto.
  • Selector de ID: utiliza un identificador precedido por el símbolo numeral.
  • Selector universal: selecciona todos los elementos.

Propiedades CSS comunes

  • color: cambia el color del texto.
  • background-color: cambia el fondo.
  • font-family: establece el tipo de letra.
  • font-size: modifica el tamaño de la letra.
  • margin: establece espacios exteriores.
  • padding: establece espacios interiores.
  • border: agrega bordes.

Ventajas de CSS

CSS permite separar el contenido del diseño. Esto facilita cambiar la apariencia de varias páginas sin tener que modificar cada uno de sus textos.
