Etiquetas y atributos HTML

¿Qué son las etiquetas?

Las etiquetas HTML permiten crear y organizar el contenido de una página web. Cada etiqueta tiene una función específica, como presentar títulos, escribir párrafos o agrupar información.

Etiquetas más utilizadas

  • h1: representa el título principal.
  • h2: representa un título de segundo nivel.
  • p: crea un párrafo.
  • ul: crea una lista desordenada.
  • ol: crea una lista ordenada.
  • li: representa un elemento de una lista.
  • a: crea un hipervínculo.
  • img: permite insertar una imagen.

¿Qué son los atributos?

Los atributos proporcionan información adicional sobre las etiquetas. Se escriben dentro de la etiqueta de apertura y algunos permiten identificar elementos, indicar destinos o describir imágenes.

Atributos comunes

  • id: identifica un elemento.
  • class: agrupa elementos para aplicar estilos.
  • href: indica el destino de un enlace.
  • src: indica la ubicación de una imagen.
  • alt: describe una imagen.
  • title: proporciona información adicional.
